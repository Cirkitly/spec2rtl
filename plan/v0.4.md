### **Project Checklist: `spec2rtl` v0.4 - The "AI Verification Engineer"**

**Project Vision:** To create an end-to-end hardware design and verification assistant that not only generates code but also uses advanced techniques like waveform analysis, formal methods, and coverage to achieve verification closure, all while learning from its mistakes and collaborating with the user.

---

#### ✅ **Phase 1: Foundational Intelligence & Collaboration (Core Agent Upgrades)**

*   [ ] **Implement Stateful, History-Aware Debugging:**
    *   [ ] In `main.py`, initialize `shared["debug_history"] = []`.
    *   [ ] Refactor `DebugAndRefineNode.prep()` to record the full failure context (artifacts + feedback) into `debug_history`.
    *   [ ] Refactor `DebugAndRefineNode.exec()` to use a new prompt that analyzes the entire `debug_history`.
    *   [ ] Update `prompts/debug_and_refine/main_prompt.md` to instruct the AI to learn from the history.

*   [ ] **Implement Human-in-the-Loop (HIL) Debugging:**
    *   [ ] Create a new `HumanInterventionNode` in `nodes.py`.
    *   [ ] This node will display the final failing code/error and use `prompt_for_input` to ask for a hint.
    *   [ ] In `flow.py`, wire the `debugger - "max_attempts_reached"` path to this new node.
    *   [ ] Wire the `HumanInterventionNode` back to the `debugger` to give it one last try with the human hint.

---

#### 🔷 **Phase 2: Advanced Verification Techniques (New Agent Capabilities)**

*   [ ] **Implement Waveform-Based Debugging:**
    *   [ ] Add `pyvcd` to `requirements.txt`.
    *   [ ] In `ValidationNode.exec()`, if the `vvp` simulation fails:
        *   [ ] Parse the generated `.vcd` file using `pyvcd`.
        *   [ ] Create a text-based "Waveform Summary" of key signals at the failure time.
        *   [ ] Pass this rich summary as part of the `error_log` to the `DebugAndRefineNode`.

*   [ ] **Integrate Formal Verification:**
    *   [ ] **(Prerequisite):** Ensure `yosys` and `yosys-smtbmc` are installed as external dependencies.
    *   [ ] Create a new `PropertyGeneratorNode` to generate SystemVerilog Assertions (SVA) from the spec and RTL.
    *   [ ] Create a new `FormalValidationNode` that runs `yosys-smtbmc` on the RTL and the generated properties.
    *   [ ] In `flow.py`, add this formal check path to run in parallel with or sequentially after the simulation validation.
    *   [ ] If formal checks fail, feed the counter-example trace into the `DebugAndRefineNode`.

*   [ ] **Integrate Functional Coverage & Test Planning:**
    *   [ ] Create a `TestPlanAgentNode` that runs after the planner to generate a `test_plan.md` from the spec.
    *   [ ] Create a `CoverageAgentNode` that reads the `test_plan.md` and injects `covergroup`s into the generated testbench.
    *   [ ] Modify `SimulationScriptGeneratorNode` to add simulator flags for enabling coverage collection and generating a report.
    *   [ ] **(Stretch Goal):** Create a `CoverageAnalysisNode` that reads the report and suggests new tests if coverage goals are not met.

---

#### 🎨 **Phase 3: Professional Workflow & Polish (Enhancing Existing Nodes)**

*   [ ] **Enhance Validation with Standard Linting:**
    *   [ ] In `ValidationNode.exec()`, add a step to run `Verilator --lint-only` (or another linter) on the generated RTL.
    *   [ ] Feed any linting warnings/errors into the `DebugAndRefineNode` as high-priority feedback.

*   [ ] **Enhance Critique with RAG-Powered Style Enforcement:**
    *   [ ] In `CritiqueAgentNode.prep()`, retrieve relevant style guide rules from the knowledge base using the generated RTL as the query.
    *   [ ] Add the retrieved rules to the prompt, instructing the agent to act as a strict style guide reviewer.

*   [ ] **Implement "Priming" via Few-Shot Examples:**
    *   [ ] Add a complete, simple "good code" example to `prompts/code_generator/generate_testbench.md`.
    *   [ ] Add a simple "good FSM" example to `prompts/code_generator/generate_rtl.md`.
